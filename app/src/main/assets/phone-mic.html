Open the secure mic link

Your phone only lets a secure page use its microphone. Install this PiKaraoke CA certificate, then open the secure link.

  1. Download the PiKaraoke CA certificate.
  2. iPhone: open Settings → Profile Downloaded and install. Then enable PiKaraoke under General → About → Certificate Trust Settings.
  3. Android: open Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Menu names vary.
  4. Open secure microphone.
